# Web 外壳与间距修复

日期：2026-11-13。范围：修复共享外壳中的页面容器间距、个人与平台导航分层、窄桌面/移动端布局。不改变业务 API、数据库、Provider 或 M1-07 / M7 验收状态。

## 发现与改动

- 个人页和平台页由 `RouteTransition` 包装，但页面容器 CSS 只匹配 `.shell-main` 的直接子元素。`.page` / `.page-wide` 实际位于 `.route-enter` 之下，因而最大宽度、居中与桌面/移动端留白规则均未命中。现已同时支持过渡包装和无包装的两种结构，普通页恢复 980px 最大宽度、宽页 1180px 最大宽度，以及桌面/手机留白。
- 个人导航现以首页、对话、连接为主入口；应用、记忆、通知和 Bot 资料作为次级入口。移动端显示首页、对话、连接、应用和“更多”，更多路由仍能保持当前入口的选中状态。
- `AppShell` 根据页面上下文区分个人、平台和组织导航。管理/连接器/工程页面不再携带个人 Provider 状态请求；组织路由使用自己的标签导航，不额外显示全局个人菜单。
- 861–1080px 显示带可访问名称与悬停提示的紧凑图标栏，避免保留 248px 侧栏后继续压缩主内容。
- 外壳间距改用 `@aven/design-tokens` 的 `space` 令牌；更新设计系统与核心旅程说明以匹配当前独立路由实现。
