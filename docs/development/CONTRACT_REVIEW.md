## 1. 变更范围与理由

- **产品与隐私**：展示、发现、self_ai/matching/sharing 独立；默认拒绝；引荐/关系用途分别确认，可先建立空上下文关系。澄清在途响应、已送达内容和撤销的保证。
- **数据模型**：候选与正式引荐/决定分离，内容版本与状态版本分离；终态重发保留历史，同一人/机会防重复关系。快照值单一来源、复合外键、预览绑定、同步失效；补齐个人会话、组织记忆、run 事件/来源与持久输入。
- **数据库权限**：普通业务/认证/Worker 池分离，NOLOGIN 函数所有者以显式策略工作，不依赖 BYPASSRLS；移除全 schema DML 与布尔 GUC 提权；普通事务能受控追加事件。
- **接口与可靠性**：/referrals 与 /matches 分开；POST JSON 创建 run、GET SSE 订阅/恢复；重放复核权限。Outbox 租约、消费回执与数据库对账补投，未知外部结果不盲目重试。
- **UI 与移动端**：修正辅助文字/必要控件边界令牌；核心旅程页面层级与双端映射；M1-07 高保真/可点击原型评审，适用状态矩阵、文字缩放、输入/返回/弱网与 development build 验收。
- **交付**：可选扩展不阻塞基础迁移；运行时锁定与实际骨架构建分阶段；部署/邮件/隐私/恢复门前移，CI 覆盖直接推送。保留最终 MVP 18 项 DoD，不将文档或确定性闭环冒充完整产品。

新增契约：[核心界面](../design/CORE_JOURNEY.md)、[核心端点](../api/CORE_CONTRACTS.md)、[ADR-007](../architecture/decisions/0007-authorization-boundaries.md)、[ADR-008](../architecture/decisions/0008-progressive-delivery.md)。同步修订 README、AGENTS、PRD、设计系统、TDD、SCHEMA、API 索引、开发计划与 ADR 索引；已接受旧 ADR 只标注取代关系，不改写历史结论。

### 2.1 颜色计算口径

按 WCAG 相对亮度公式：sRGB 通道 c 归一化到 0–1，c≤0.04045 时除以 12.92，否则 `((c+0.055)/1.055)^2.4`；亮度为 `0.2126R+0.7152G+0.0722B`，对比度 `(较亮+0.05)/(较暗+0.05)`。

组合范围：浅/深主题的 foreground/secondary/tertiary、accent、destructive、success、warning、info 对四种基础表面；primary/accent/destructive 按钮文字；focus-ring/control-border 对基础表面。普通文字/按钮阈值 4.5:1，必要非文本边界 3:1。装饰分隔线不声称满足控件识别要求。

修订示例：浅色辅助文字 #707070 在 #F5F5F4 上约 4.539:1，深色 #8B8F96 在 #202226 上约 4.906:1；对应控件边界约 3.402:1、3.523:1。以上是不含透明度/叠层的静态数值，不能推导实际页面已满足 WCAG。
