AVEN 当前已接入首批个人 Web：登录、Mock SSE 对话、手工记忆、候选记忆复核、记忆编辑撤回、个人邀请/消息、站内通知与通知偏好，以及连接器调用与会话小组件；仍不是完整 AI 社交应用。工程诊断迁至 `/diagnostics`，移动端个人工作区已编码，原生运行待验收。限定范围与实际验证见 [WEB-01](WEB_PERSONAL.md)、[WEB-02](WEB_02.md) 与 [WEB-03](WEB_03.md)。

## 最新工作区：聊天布局与回复展示

个人 Web 改为纯黑聊天界面、简洁输入、手机五入口与桌面导航。回复支持安全的列表/代码与复制，辅助功能进入主内容区；切换保留对话，暂停清除派生结果并保留来源复核。Mock 增加确定性示例，真实模型尚未启用。371 项单测、11 项真实聊天链路与工作区 5 项定向回归通过；Web/Worker 已更新，浏览器/设备视觉未重新验收。范围与限制见 [WEB_CHAT_02](WEB_CHAT_02.md)。

## 最新修复：注册冲突与邮件失败

重复邮箱现返回明确 ACCOUNT_ALREADY_EXISTS，并引导登录/找回密码。邮件失败后已创建账号不会再报整体注册失败，未验证账号凭正确原密码可重发，不覆盖原资料并保留频控。352 项单测、10 项注册与 11 项恢复回归通过；API/Web 已重新部署，公网合成冲突检查通过。无迁移，真实邮箱投递仍待实测。见 [注册修复](WEB_REGISTRATION_FIX.md)。

## 当前增量：欢迎入口、无闪烁复核和 SMTP

最新个人 Web 入口已按用户新图改为静态彩色角色欢迎页，点击后打开认证面板；修复匿名会话 focus/pageshow 引起的表单卸载与输入丢失。部署邮件已从文件 sink 切换到 SMTP，密码恢复邮件含一次性 fragment 链接，客户端立即清除 URL 令牌。348 项单测、11 项真实恢复检查和线上多尺寸交互通过；SMTP TLS/认证通过，收件箱实际送达仍待实测。见 [WEB_LOGIN_02](WEB_LOGIN_02.md)。下面记录保留各自时间范围；APK 保持暂停，正式设计和生产试点门未关闭。
