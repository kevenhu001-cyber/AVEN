# WEB-08：交互细化与消息动效门控

日期：2026-11-13。范围是 WEB-07 之后的交互逻辑与动画细化，不改变页面路由、Halo 视觉基调、真实 Provider 解析、Open Connector 授权或数据库迁移。

## 交互改进

- **消息入场门控**：用户气泡从右下、助手气泡从左下弹出，思考指示器同步入场；动画由 `data-fresh` 控制，只对本次进入页面后新增的消息播放。重新打开已有对话时不会重播历史气泡。
- **流式首字入场**：助手气泡是否播放动画按「该 turn 是否已经出现过回复」判断，而不是按状态判断；因此首个 token 到达时气泡仍会弹入，后续增量不重复触发动画。
- **流式渲染开销**：`RichText` 用 `memo` 包装，流式更新时不再重复扫描全部历史消息文本。
- **未读回复**：滚动离开底部后，悬浮按钮显示未读回复数量（超过 9 显示 `9+`）；回到最新消息、发送消息或手动回到底部时清零。
- **失败与取消重试**：`failed` / `cancelled` 的提问显示「再试一次」，直接重发原提问；仍保留 `unknown` 的「核对发送结果」与 `disconnected` 的「重新读取回复」。
- **部分回复复制**：已产生文本且不再处于活动状态的回复即可复制，包括已取消或已失败的回复；剪贴板不可用时沿用统一提示。
- **输入长度提示**：草稿超过 7000 字显示 `n/8000` 计数，达到 8000 字上限时切换为警告色。
- **全局 Escape**：查找栏打开时，`Escape` 可在任意焦点位置关闭；菜单与 Sheet 已处理的 `Escape` 不会重复触发。
- **查找参数同步**：`/chat?q=` 在组件复用、仅查询参数变化时也会立即打开查找栏并填入关键词。
- **控件反馈**：连接应用列表行、应用项、首页 Bot 卡片、底部导航激活图标补充过渡与按压反馈，并保持键盘焦点可见。

## 减少动态

- 新增气泡、元信息、流式光环与控件过渡均纳入 `prefers-reduced-motion`：动画与过渡缩短到 1ms，按压位移取消，光标/打字/骨架/吉祥物动画关闭。
