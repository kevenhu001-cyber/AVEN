## 校园网络检查清单

在真实试点网络、不同时间段与不同运营商出口执行并记录：

- [ ] DNS 解析、HTTPS 证书链、TLS 版本与是否存在拦截代理。
- [ ] API 延迟 p50/p95、首包时间、SSE 长连接稳定性与断线重连。
- [ ] WebSocket 是否可用（如后续需要）；代理/网关空闲超时。
- [ ] 上传/下载带宽与丢包；弱网下的超时、重试与幂等。
- [ ] 邮件域名 SPF/DKIM/DMARC；出站 25/465/587 是否被封。
- [ ] IPv6 可用性与回退；CGNAT 对回连/推送的影响。
- [ ] 校园统一身份/网络登录是否影响外部 OAuth 或邮件链接。
- [ ] 高峰时段（选课、考试、晚间）与宿舍/实验室/教学区差异。

## 移动网络检查清单

- [ ] 中国移动/联通/电信 SIM 与主流 Android 中端设备。
- [ ] 4G/5G、弱网、地铁/电梯/校园建筑内的恢复行为。
- [ ] IPv6-only/CGNAT 环境下的 API、SSE、推送与深链。
- [ ] 后台切换、进程被杀、网络切换后的会话与幂等。
- [ ] 真实设备上的 Safe Area、键盘、文字缩放与长列表。
- [ ] 发布构建（development build/APK）安装与升级，不以 Expo Go 代替。
