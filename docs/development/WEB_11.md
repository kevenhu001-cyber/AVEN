# WEB-11：个人 Web 精致化与对话入口收敛

日期：2026-11-14。用户在完成项目与 ChatGPT / Grok / Vercel Geist 对比分析后授权开始优化。决策见 [ADR-021](../architecture/decisions/0021-personal-web-refinement.md)。本包只调整既有前端呈现、入口和共享视觉规则，不新增业务能力。

## 实现范围

- 首页 `/` 与 `/chat` 共用 `ChatPageClient` 和既有 `AppStateProvider`，首次即可提问；跨资料页返回保留内存中的回复和草稿。移除旧角色首页的搜索入口，保留 `/chat?q=` 和聊天菜单查找。侧栏把重复的首页/对话合并成一个入口；开启新对话仍走显式重置。
- 桌面侧栏 248px、折叠 72px；正文与输入区最大 760px，普通页面 960px、宽页 1120px。布局尺寸新增共享令牌，由 CSS 生成器同源输出。
- 手机聊天页隐藏业务底栏，聊天顶栏通过 `ShellNavigationContext` 打开现有 Radix 导航抽屉；其他页面保留底栏与“更多”。不增加第二套抽屉或全局事件。
- 保留正圆角色，首屏角色缩至 48px，问候/输入/快捷问题组成一个区域。去掉聊天返回按钮与 Bot 标题的胶囊底座，更多与手机菜单为透明图标按钮。
- 输入区只常驻连接器、文字、发送/停止；移除未开放语音占位，空输入的发送按钮禁用。主要输入按钮 44px；保留 IME、Shift+Enter、字数限制和停止逻辑。
- Geist / Noto Sans SC 优先，系统字体回退，代码明确采用系统等宽字体。Halo 侧栏退至 `#101010`，主画布保留 `#141414`，正文柔白 `#EDEDED`，次文字 `#A1A1A1`，用户气泡 `#303030`，保留蓝色焦点与独立状态色。
- 对齐现有个人页面、共享外壳的文字角色和 400/500/600 字重；按钮、Input、Textarea、Card、Alert、Dialog 使用统一圆角。助手长正文开放排版，结构化结果、授权预览等继续有独立容器。
- 新消息入场缩短到 180ms、小幅位移；保留 `data-fresh` 门控、增量 Markdown、流式节流和减少动态。复制工具保持可发现，输入焦点用实线轮廓，不使用焦点阴影；抽屉去掉装饰阴影。
- 修复代码高亮的浅色选择器：原先 `:root:not(.aven-theme-halo)` 在 Halo 类位于页面容器时仍会命中，导致代码普通字符与部分语法颜色过暗。现在按根节点下是否存在 Halo 容器判断，补充实际渲染回归。

## 文件与架构

- `packages/design-tokens`：颜色、排版、布局、圆角、时长及生成 CSS，既有对比度测试同步。
- `apps/web/src/components/shell`：合并导航、共享抽屉入口、页面容器和侧栏。
- `apps/web/src/components/ui`：按钮、表单、卡片、提示和对话框的基础形态。
- `apps/web/src/features/personal`：共享欢迎状态、聊天、Markdown、图标和个人页面排版。
- `scripts/lib/personal-web-nav.mjs`：新对话改用当前聊天菜单，不依赖已移除的独立首页按钮。
- `tests/e2e/personal-state.spec.ts`：更新入口导航，增加首页直接发送/草稿保留和长回复宽度/窄屏回流回归，扩展移动抽屉与代码可读性断言。

无数据库迁移、API 契约、权限、Provider、Open Connector 或业务状态机变化。Web/Mobile 继续共享令牌，但本轮没有原生页面或真机验收。

## 适用状态与交互

| 状态 | 本轮行为与检查 |
| --- | --- |
| 未登录/会话失败 | 沿用登录、重连和私人视图门；既有失败与上游私密文本测试保留 |
| 空对话 | 首页直接可输入；发送禁用直到有有效文字；快捷问题可发送 |
| 已有对话 | 首页与聊天路由使用同一内存工作区；访问资料页返回不丢回复/草稿，不重播历史气泡 |
| 生成/取消/失败 | 保留流式解析、停止、取消部分正文、失败清除与重试/核对操作 |
| Markdown/公式/图表 | 保留安全边界、代码复制、Mermaid 源码切换与局部横向滚动 |
| 查找 | 菜单与快捷键可达，查找栏出现时为正文预留空间，原 URL 查找兼容 |
| 桌面展开/折叠 | 248/72px，沿用浏览器偏好持久化与当前路由标记 |
| 手机聊天 | 隐藏业务底栏，顶栏抽屉可开关、Escape 关闭、导航后关闭 |
| 手机其他页面 | 保留底栏“更多”与顶栏入口，不因聊天减法而丢失导航 |
| 减少动态 | 保留既有停止位移/循环动效和增量渐显门控 |

## 实际检查

```bash
corepack pnpm format:check
corepack pnpm lint
corepack pnpm typecheck
corepack pnpm test
corepack pnpm --filter @aven/web build
PLAYWRIGHT_CHANNEL=chrome corepack pnpm test:e2e:personal
```

- format、lint（含依赖边界）、完整 typecheck 20 个任务、单测 53 文件 / 370 项、Web 生产构建已通过。
- 个人 Web E2E 40 项通过（desktop / mobile-web，包含新增跨页状态、阅读轴、窄屏、导航和代码颜色断言），最终独立复跑退出码为 0。
- 另外使用生产构建在本地 3108 端口运行合成 HTTP/SSE 夹具，检查首页 → 手机抽屉 → 发送 → 中英混排/代码/表格回复 → 账号页面。使用项目 Playwright + 本机 Chrome；当前没有 Browser 插件技能，未调用新的浏览器插件或安装依赖。夹具截获所有业务请求，无真实账号、模型调用或外部操作。
- 实测 1440px 桌面：助手正文与输入框均为 760px，左边缘均为 464px。320、390、768、1024、1440 CSS px 没有页面横向溢出；夹具页面未记录运行异常或 console error。检查截图包括 1440×900、390×844、320×740，使用 `view_image` 查看。
- 已重启本机 3000 端口 Web 服务以加载最新构建：首页 HTTP 200，首页引用的 18 项静态资源全部 HTTP 200。此项仅为本机服务更新，没有远程部署或生产发布。

首次 E2E 中，新增跨页检查因缺少记忆列表/通知偏好夹具而触发既有会话失效保护；补齐合成响应后重新运行完整套件，未放宽会话保护。

## 限制与后续

- 没有新增会话历史 API、本地正文缓存或历史恢复；刷新后仍遵循原有内存状态边界。
- 未建立截图自动差异基线，截图人工核对不等于视觉回归系统或正式设计评审。
- 本轮没有真实模型长回复性能、真实软键盘、200% 文字放大、读屏、原生真机或生产验证；合成 SSE 不代表模型能力或生产性能。
- 本轮共享组件和视觉语义已覆盖其他页面，未重新设计每个业务表单、记忆复核和授权流程；相关业务和安全边界保持现有实现。
- 不改变 M1-07 REVIEW、原生与生产验收状态。后续可独立推进真实设备与长内容性能、页面状态专项审查和视觉基线。
