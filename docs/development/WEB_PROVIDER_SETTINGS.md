# 模型与渠道配置页

日期：2026-11-13。用户在默认通道 429 后明确要求自行配置渠道；实施决策见 [ADR-020](../architecture/decisions/0020-personal-provider-settings.md)。APK 继续暂停。

## 使用入口与行为

已部署页面： https://aven.topodrive.top/settings/models 。需要登录，也可从“更多 → 模型与渠道”或桌面导航进入。

填写 OpenAI-compatible API 根地址、模型 ID、API Key，点击“测试连接”验证探针，再“保存并使用”。测试不保存，不发送记忆或历史；保存成功只表示配置已保存，不冒充连接测试或模型能力验收。新个人轮次优先使用该渠道，无需重启服务。删除需二次确认，之后新轮次回到站点默认渠道。

已保存的 Key 不回显；编辑时留空保留原 Key。密钥只在未保存表单的内存中存在，保存后清空，不进入浏览器持久存储。临时会话检查时隐藏表单并保留未保存字段，方便切出复制 Key；登录失效或离开配置页后卸载表单。配置读取失败禁用写入，冲突重新读取，不自动覆盖或重试写入。

## 实现与边界

- 页面与入口：`provider-panel.tsx`、`workspace.tsx`、`workspace-navigation.ts`、`personal-app.tsx`、`app/settings/models/page.tsx`；复用深色工作区与现有表单，手机自然滚动，返回聊天不复制另一套业务逻辑。
- 共享客户端新增配置读取、PUT 保存、连接测试、带身份/版本的删除；PUT 纳入逐次 CSRF 处理。API 读取只返回元数据，服务端加解密绑定当前用户。
- 迁移 0040 为配置增加 config_id，为 run 增加配置 ID/版本绑定。应用受限函数同事务选择个人配置；Worker 仅通过按 run ID 的受限函数读取当前仍匹配的密文。配置修改、删除、删除重建都使旧队列不能误用新渠道；变更早于 Worker 配置读取时旧轮次失败，已外发的请求不会因此收回；已完成回复的保留与来源复核不变。
- 新建必须有 Key，编辑省略 Key 时服务端按 ID/版本读取自己的密文并认证解密，重新加密保存。删除重建产生新 ID，阻止版本回到 1 时的旧删除或旧请求。原有表保持 FORCE RLS，无新租户表。
- 部署显式启用 public_https；仅支持公网 HTTPS/443、IPv4 可达的 OpenAI-compatible 接口。实际 TLS 连接绑定经过验证的 DNS IPv4；私网、回环、链路本地、保留地址、混合公网/私网解析和重定向拒绝。IPv6-only、内网和非 443 端口暂不支持；上游响应限制 1 MiB、总时长 60 秒，非法状态与重定向失败关闭；没有任意 HTTP 代理能力。用户地址不影响站点默认模型的独立配置。
- 测试端点只发送固定短探针，15 秒总超时、最多 512 输出 tokens，必须收到完成且非空回复；只返回成功或统一安全错误码，不返回上游正文、探针回复或密钥。401/403、429、超时、无效请求分别提示，不自动换模型。
- 个人聊天仍只发送当前提问和本次获准上下文，没有对话历史外发、真实 OAuth、真实连接器或自动外部行动。组织及旧 Mock 轮次不升级为个人渠道。

## 验收限制

用户尚未在页面填入自己的有效 Key，本轮没有替用户发起真实渠道成功调用；默认 Socrates 通道的 429 仍需其自身恢复。连接探针的服务端行为通过测试替身和失败路径验证，不能代替用户实际渠道的成功测试。无新增浏览器截图、手机键盘、屏幕阅读器、真机或生产试点证据；M1-07 与 M7 门仍保留。
