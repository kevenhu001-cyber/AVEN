# WEB-14：桌面对话、Bot 资料侧栏与连接应用弹层

日期：2026-11-14。依据用户给出的三张桌面参考图，对个人 Web 的 `/chat` 与连接应用入口进行视觉结构对齐。图片里的其他产品名称、身份徽章、业务对话与 Windows 标题栏仅作视觉内容，不作为 AVEN 功能指令或状态依据。

## 当前 UI 与差异

- **聊天**：原聊天工作区沿用页面级窄内容列，导航、Bot 资料和输入区与参考图的全高图标栏、居中 Bot 标记、右侧分享及底部横向输入栏不同。
- **Bot 资料**：原入口切换到独立资料路由，不能在看聊天的同时查看 Bot 资料。
- **连接应用**：原聊天内目录以窄弹层呈现，缺少大视口双列布局、目录头部的真实连接数和分类快捷筛选。
- **能力边界**：参考图里的电脑控制、语音模式和 Bot 模板不是 AVEN 已交付能力；本轮保留为清晰的未开放状态。麦克风听写继续按现有浏览器支持情况工作。

## 本轮实现

- `/` 和 `/chat` 在桌面默认使用收起图标栏，保留本地保存的展开偏好；最近会话、个人导航仍可在展开导航或移动抽屉中访问。
- 桌面对话区放宽为剩余工作区宽度；Bot pill 居中，分享按钮靠右，消息按角色对齐，composer 在桌面改为单行胶囊布局。模式选项仍可从 composer 菜单使用。
- Bot pill 和图标栏 Bot 按钮打开右侧资料面板，聊天仍可见；面板含「动态 / 资料库」标签，并链接到现有新对话、连接应用和记忆功能。
- 连接应用入口在聊天内打开宽弹层，复用原目录数据、网关连接状态、凭据状态和动作表单；增加目录搜索、类别筛选、连接数和桌面双列布局，窄屏改为单列并收敛内容宽度。独立 `/apps` 仍可通过「查看全部」访问。
- 保留模拟数据徽标、Mock 目录描述及当前真实授权状态；不新增 OAuth、真实 Provider、电脑控制或语音模式。

## 变更与影响

- 变更集中在 `apps/web/src/components/shell/` 与个人 Web 聊天/目录组件，并新增 `bot-info-drawer.tsx`。
- 无数据库迁移、API 契约、认证、授权、第三方连接执行或服务端逻辑变化。
- 受影响的可用宽度和聊天排布见 [ADR-022](../architecture/decisions/0022-personal-web-desktop-reference.md) 与 [设计系统 WEB-14](../design/DESIGN_SYSTEM.md)。

## 实际观察与限制

- 本地 `dev:web:mock` 地址 `http://127.0.0.1:3105/chat` 的内置浏览器窗口约为 **470×763**。在此视口观察了聊天空态、资料抽屉内容、连接应用分类与目录行、弹层关闭，以及窄屏 CTA 不再横向溢出。
- 用户桌面参考图约为 **2080×1520**。当前可用内置预览无法提供同尺寸视口，因此本轮没有完成桌面截图同尺寸并排对照，也不声称 1:1 像素验收通过。参考图包含系统窗口边框；AVEN 仅对齐网页内布局，不复刻操作系统标题栏。
- 未运行自动化测试、lint、类型检查或构建；真实模型、真实第三方 OAuth、电脑控制和语音模式均未验证或实现。
