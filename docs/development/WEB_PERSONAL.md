# WEB-01：个人 Web 首批真实接入

日期：2026-11-12。授权范围见 [ADR-017](../architecture/decisions/0017-personal-web-increment.md)。这是个人 Web 的限定增量；M1-07 整体仍 REVIEW，不代表双端设计、完整 MVP 或可发布验收。

## 已实现

- `/` 使用个人 Web；原工程探针迁至 `/diagnostics`，组织路由保留。
- 邮箱注册、Web Cookie 登录、邮箱验证码验证、当前会话与退出。开发邮件仍为服务器本地文件，不会向用户真实邮箱投递。
- 真实 API → Outbox → BullMQ/Mock Worker → SSE 对话；排队、生成、完成、取消、失败与断流状态。未知创建结果手动沿用原幂等键核对，断流仅重读原 run，不自动创建新任务。没有历史列表，刷新后不会自动重放正文。
- 本人手工确认兴趣记忆，`self_ai` 与 `sharing` 默认均不勾选；准备共享与实际发送分开。
- 对方主动分享 `aven:<UUID>` 连接码后，选取允许共享的信息，查看服务器实际快照、接收方、用途和期限，再明确发送。接收方接受/拒绝，发送方撤回/撤销；建立连接不扩大资料用途。连接码不是登录凭据。
- 已有连接真实消息收发、历史游标读取、单方删除；站内通知分页、手动刷新与标为已读。没有即时推送。
- 大圆角气泡、胶囊输入区、紧凑间距与正圆无手脚角色。idle/thinking/happy/sleepy 随实际状态切换，SVG 尊重减少动态偏好；深色模式保留白色圆形衬底，避免黑色角色融入背景。复用 Socrates 本地 Geist/Noto Sans SC，字体许可随资产交付；常见操作使用原型中 Lucide SVG，保留圆头、圆连接与圆角。

## 架构与安全

`apps/web/src/features/personal` 按认证、对话、记忆、连接、消息、通知拆分。共享 `api-client/personal.ts`、`agent.ts` 和 contracts 验证输入与响应，Web 不依赖数据库或领域服务。无数据库迁移、API 端点或服务端权限变更。0039 仍未应用。

浏览器只通过同源重写访问 API，HttpOnly 会话 Cookie 与逐次读取的 CSRF Cookie 分开；拒绝 Web 登录返回移动 Bearer token。私密正文、验证码和令牌不写入 localStorage/sessionStorage。会话隐藏、离线、窗口恢复、页面恢复与跨标签会话变化先隐藏私人视图，再验证身份；401 清空整个工作区。流式来源失败/断流清除已渲染回复。后台恢复后必须手动重读，不能靠旧正文继续展示。

写请求不自动重试。Agent/邀请/消息的结果未知时保留请求标识；明确的 4xx 拒绝允许修正输入。记忆创建端点没有幂等契约，未知结果提示先刷新核对；不声称所有业务写入都有 exactly-once。显示中的资料不能收回已送达字节，服务器继续在每次读取校验当前授权。

| 范围 | 状态与行为 | 实际证据 |
|---|---|---|

| 对话 | 空白/输入中、IME、换行、排队、生成、完成、停止、未知结果、断流、离线 | 真实 Worker/SSE；浏览器传输故障注入核对同 key 同 run、截断清理/重读、实际停止终态 |
| 记忆 | 空/加载/保存/错误；用途默认拒绝 | 浏览器创建与实际 API 列表；共享用途单独确认 |
| 连接 | 空、预览、待回应、接受、拒绝、撤回、授权变化 | 双独立账号实际预览不发送、发送/接受/建联；旧合成待回应夹具仅受控撤回 |
| 连接消息 | 空/加载/分页、发送、未知、读取失败、删除确认 | 两个独立浏览器会话实际发送/读取；权限/分页/删除后端原有测试继续保留 |

本轮真实联调已验证：两个隔离账号注册/登录、开发邮件验证、Mock 回复、手工记忆、连接预览/接受、消息收发和站内通知。初次流程在邀请/通知断言处修正了测试选择器与手动刷新时机；这两处不是业务通过的替代。最终复验沿用已建立的合成连接，18 项通过；独立恢复脚本 7 项通过，并在生产构建再次通过；生产 Mock 对话与字体加载也已实际核对。原始预览/发送/接受在初次实跑完成并留有命令输出。

### 复跑

先构建并启动本地 PostgreSQL、Redis、API、Worker 与 Web，显式设置 `AI_PROVIDER=mock`、`AUTH_DEV_MODE=true`；Web/API 默认 3000/3001，`WEB_ORIGIN=http://127.0.0.1:3000`。脚本仅允许 localhost/127.0.0.1：

```bash
node scripts/personal-web-verify.mjs
node scripts/personal-web-recovery-verify.mjs
PLAYWRIGHT_CHANNEL=chrome corepack pnpm test:e2e
```

前两个脚本写入独立合成账号与少量业务数据，不重建数据库、不清除全局限流、不修改真实用户。`.data/personal-web-*` 保存合成夹具和浏览器测试会话，均被 Git 忽略；重新运行可复用，登录态失效时重新登录。恢复脚本依赖 B 的合成登录态，故须先执行主脚本。首次运行需要本地开发邮件目录 `.data/mail`。不要将这些文件发布。第三条使用专门的无依赖探针服务器，含明确标注的 UI 传输夹具，不能替代前两条真实业务联调。

最终工程命令结果见本文件末尾与开发计划执行记录。
