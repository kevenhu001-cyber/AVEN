# WEB-07：交互打磨与消息动画

日期：2026-11-13。范围是 WEB-06 之后的交互与动效优化，不改变页面结构、数据库或真实 Provider 接入方式。

## 交互改进

- **消息入场**：用户气泡从右下弹出，助手气泡从左下淡入上浮，思考中的三点指示器同步弹出；每条新消息只播放一次，不因流式更新反复触发。
- **流式平滑**：SSE 文本增量先进入 `requestAnimationFrame` 缓冲，再按帧写入 React 状态，避免每个 token 触发一次渲染；完成、取消、失败和断线时立即冲刷或清空缓冲。
- **回复操作**：完成后的助手消息提供「复制」按钮，复制成功显示「已复制」；剪贴板不可用时给出提示，不静默失败。
- **快捷提问**：空对话提供「帮我整理今天的想法」「我最近在忙什么？」「连接 Gmail」三个快捷入口，直接发送。
- **键盘与焦点**：`Ctrl/Cmd + K` 打开聊天内查找；桌面端进入对话自动聚焦输入框，移动端不主动弹出键盘。
- **页面切换**：`template.tsx` 为个人与平台路由组提供 300ms 的淡入上浮过渡，Provider 状态不因切换丢失。
- **控件反馈**：按钮、胶囊、卡片、侧栏导航增加 hover/active 过渡与激活指示；骨架屏改为移动渐变；输入框聚焦增加柔和光环。
- **移动端**：对话页隐藏重复的 Shell 顶栏，只保留对话自己的返回/Bot/更多头部；底部导航保持不变。
- **减少动态**：`prefers-reduced-motion` 覆盖新的 `.personal-app`、`.shell`、`.diagnostics-page` 与 `.route-enter`，并关闭气泡/骨架/光标动画与按压缩放。
