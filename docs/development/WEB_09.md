# WEB-09：助手正文渲染与增量渐显

日期：2026-11-13。范围：个人 Web 助手正文、代码复制、查找适配、流式取消竞态，以及下一包会话历史设计。没有新增数据库迁移或已开放 HTTP 端点。

## 实现

- 新增 `apps/web/src/features/personal/markdown/`：`react-markdown` + GFM + `remark-math` / `rehype-katex`。支持标题、强调、引用、列表、表格、代码与公式；`\(...\)` / `\[...\]` 按代码、链接、HTML 与已有公式边界进行归一化，保留原始回复供整条复制。
- KaTeX 样式、字体随本地构建输出，直接依赖与渲染器使用相同的 0.16.47 版本。`trust:false`、公式扩展/尺寸上限，错误公式显示可读源码；不宣称支持全部 LaTeX 宏包。
- 代码块显示语言和复制按钮，复制不夹带查找高亮或按钮文本；流式继续修改代码时重置复制反馈。代码、表格、长公式局部滚动，助手容器从 `p` 改为 `div`，避免块元素非法嵌套。
- 用户输入沿用纯文本与行内代码。助手查找按解析后的文本叶子计数，包含代码和链接文字，排除 Markdown 标记、URL 目标、图片说明和公式内部。公式生成 DOM 不进入查找高亮，避免 MathML 与视觉公式重复命中。
- 新文本叶子与追加片段播放 220ms 透明度渐显；保留既有新气泡门控，历史回复不重播。每个文本叶子最多保留 32 个动画片段，旧段合并，UTF-16 代理对不跨 span 拆开。没有人工逐字延迟队列；查找结束不重播旧片段，低动态模式禁用渐显。
- 禁用原始 HTML，链接执行协议过滤，远程图片仅显示占位，不请求跟踪像素；模型 SVG 不注入。公式拒绝受信任命令。渲染不添加任何工具执行、自动跳转或数据发送能力。
- 取消 API 直接返回终态时，先冲刷并取消待执行 rAF，再更新终态，避免残余帧将状态改回 `running`；失败终态清除派生回复。移除流式气泡光影，使用令牌边界。
- 导航辅助脚本补充 `findInChat`。下一包的接口、授权复核、游标一致性和小组件恢复方案见 [会话历史设计](CHAT_HISTORY_DESIGN.md)，该方案尚未实施。

## 状态与验证范围

| 状态 | 行为 |
| --- | --- |
| 排队、等待首字 | 沿用原有状态文字与思考指示器 |
| 增量生成 | 渲染当前 Markdown；未闭合代码围栏保持代码展示，完整公式到达后渲染 |
| 完成 | 保留已渲染正文，整条复制输出原始 Markdown，代码可单独复制 |
| 取消 | 保留当前已接收部分、停止生成状态，不留下待处理文本帧 |
| 失败、来源失效、会话失效 | 沿用受限正文清除，不用动画保存可继续显示的副本 |
| 历史返回 | 当前内存中已有回复不重播；刷新后的历史读取尚未实现 |
| 减少动态 | 正文直接显示，状态文字仍可读 |

E2E 使用合成认证与 fetch 字节流，实际经过共享客户端 SSE 解码和页面渲染；不代表真实模型、网关网络、外部插件或原生端验收。
