# ADR-011：个人连接邀请与独立授权

- 日期：2026-11-12
- 状态：本轮实施，验证结果记录在交付文档
- 补充 ADR-007/008；不改写组织引荐的历史结论

## 决策

用户明确 AVEN 对话优先，社交连接以插件与小组件呈现。现有 referrals/relationships 强制绑定组织与机会，不能伪造机会来实现个人连接。

新增 `connection_previews`、`connection_invitations`、`peer_connections` 与 `connection_events`。发送方在预览后确认，接收方通过独立会话决定；接受原子创建无序用户对唯一连接。个人连接暂不成为旧组织关系空间，不使用现有关系/活动 API，也不复制共享正文。

复用 consent_grants/items/events，新增专用 `connection_invitation` 用途及 `connection_invitation_id` 绑定。预览只支持本人允许 sharing 的已确认记忆正文，固定短期限和实际值。快照只读不可变，读取实时授权，来源收紧同事务使快照 stale。

所有写入由非表所有者、NOBYPASSRLS 的 aven_function_owner 受控函数执行，普通应用无直接 DML。成对事务锁与唯一索引处理双向邀请/并发接受；发送必带幂等键，重放仅返当前元数据。状态事件审计不存正文；本轮列表轮询承担接收，不假造通知投递。

## 验证门与后续

须验证预览不泄露、来源变化重预览、独立决定、唯一建联、重试、反向并发、跨用户 RLS、撤销/到期/删除/用途收紧、无复活，以及空库和升级迁移。正式 UI 仍受 M1-07 评审门约束。

个人连接发现、拉黑与举报、通知和共同会话在独立工作包设计；不得把本轮底座描述为完整跨终端 AI 社交应用。
