# ADR-018：个人 Web 采用 Halo（Grok Bot 风格）深色界面

- 日期：2026-11-13
- 状态：已接受（限定个人 Web 视觉与交互结构）；验证见 [WEB-04](../../development/WEB_04.md)
- 部分取代 [ADR-017](0017-personal-web-increment.md) 决策 1 中“沿用 v0.4 浅色气泡”的视觉方向；ADR-017 的功能范围、安全与 Mock 限制全部不变。

## 背景

用户提供 6 张 Grok Bot（“Halo”）手机截图（首页、Bot 资料页、对话、“…”菜单、滚动状态、连接应用页），要求重写个人 Web 的 UI 与动画并尽量模仿其界面与功能。现有个人 Web（WEB-01–03）为浅色侧栏 + 对话布局，连接器与面板以居中对话框呈现。

## 决策

1. 个人 Web（`/`）固定使用 Halo 近黑主题：`@aven/design-tokens` 新增 `colors.halo`（与 light/dark 同键、同一对比度测试）、`haloExtras`（用户气泡、授权蓝、徽标橙、开关、高亮）、`easing` 与 `duration.screen/sheet`、`radius.menu/sheet/tile`；生成 `.aven-theme-halo` 与 `:root:has(.aven-theme-halo)` 变量块。组织控制台与 `/diagnostics` 不受影响。
2. 结构改为手机优先的屏幕栈：首页 → Bot 资料页 / 对话页，推入/返回滑动转场；桌面为居中 480px 手机列。记忆、连接、通知、账号与占位说明改为底部 Sheet；连接器目录改为全高“连接应用”Sheet（精选插件 + 按类别分组 + 搜索）。
3. 资料页条目只映射已有能力：资料库 → 记忆与上下文；通知开关 → 既有四项通知偏好（主开关，`expectedVersion` 乐观锁，冲突回读）；连接应用、我的连接、通知中心。电脑、添加到 Slack、定时任务、分享 Bot、编辑 Bot、语音输入/语音对话不存在于本范围，显示为明确的“尚未开放”占位，不伪造状态。
4. 连接器授权仍为 Mock：对话内授权卡片按“授权 → 确认范围（Mock）→ 授权中 → 已连接（Mock）”变化，只在当前页面内存中记一个标志，不跳转第三方、不请求令牌、不改变服务端 `credentialStatus`；已连接后可直接用卡片上的动作以 `allowLive: false` 调用服务端 Mock 适配器。用户消息中出现“连接/授权 + 连接器名”时，页面按本地规则在该轮后插入授权卡片，并标注“本页提示 · 非模型回复”。
5. “…”菜单：查看资料、在聊天中查找（本页高亮与上下跳转）、分享为模板（仅把用户提问复制到剪贴板，不上传、不公开）、新对话。
6. 动效全部为 CSS（无新依赖）：角色 8 种状态移植自 `docs/design/prototypes/mascot-motion`（idle 加入左右张望），对话流式时 thinking、授权成功 happy；屏幕滑动、Sheet 上滑与遮罩淡入、菜单从触发角缩放淡入、消息上浮、打字指示、头部回顾胶囊变形、回到底部按钮淡入、按压缩放、开关弹簧、授权按钮状态切换。`prefers-reduced-motion` 下停止循环与位移，保留状态。
7. 不内置第三方品牌 Logo（仓库无品牌资产授权），连接器以中性白色方块 + Lucide 类别图标呈现。

## 备选方案

- 保留浅色并只换配色：不满足用户“模仿 Grok 截图”的要求。
- 引入动画库（Framer Motion 等）：CSS 已能覆盖全部动效，且新依赖需额外评估；不采用。
- 首页直接显示对话：与截图不符；对话在首页点角色或“+”进入。

## 后果

- 既有 Playwright 复验脚本与 E2E 需要先从首页进入对话、从“我的账号”Sheet 打开记忆/连接/通知；已抽出 `scripts/lib/personal-web-nav.mjs`。
- M1-07 双端设计评审仍为 REVIEW；本 ADR 不代表正式设计验收、原生端实现或真机证据。
