# ADR-020：用户自配模型与渠道

- 日期：2026-11-13
- 状态：已接受（用户明确要求配置页）
- 补充 ADR-019 的用户自配通道，不改变外发范围。

用户在默认通道 429 后明确要求自行配置渠道。个人 Web 增加模型与渠道页面，保存、测试与删除个人配置；新个人轮次优先使用该配置，删除后回默认通道。密钥服务端加密，读取只返回元数据，客户端不持久化。测试只发送固定无私人信息的短探针，不自动发送用户记忆。

新增迁移绑定 run 到配置的不可变 config_id 与 version；删除重建也换 ID。Worker 仅通过按 run 绑定的受限函数获取密文，若变更/删除早于 Worker 的配置读取，旧轮次失败，不静默使用新凭据；已外发的请求不能收回。普通应用角色不能读取任意用户密钥，组织不使用个人渠道。

支持用户填写公网 HTTPS OpenAI-compatible 地址；仅 443，无 URL 凭据、查询或 fragment。上游请求使用每次连接的 IPv4 DNS 校验与连接绑定，拒绝所有私网、回环、链路本地、保留地址和重定向；IPv6-only 通道暂不支持。不开通任意内网代理或用户工具调用。

迁移 0040 依赖正常有序迁移流程，先在隔离库验证再应用本机。既有 pending 0039 作为顺序前置函数迁移一并验证，不将其解释为真实日历接通。无新租户表，FORCE RLS 保持。
