# ADR-021：个人 Web 对话入口与视觉规则收敛

- 日期：2026-11-14
- 状态：已接受（用户在 UI 分析后明确要求开始优化）；验证另见 WEB-11 交付记录。
- 部分取代 ADR-018 的独立角色首页、手机业务底栏与气泡排版；权限、用途、确认与撤销规则不变。

## 决策

1. `/` 和 `/chat` 使用同一对话组件与现有内存状态。初次进入直接显示可提问的空状态，已有对话不因回到首页而丢失；开启新对话仍显式重置。不新增历史列表或本地正文缓存，保留 `/chat?q=` 查找兼容。
2. 桌面侧栏 248px，折叠 72px；正文和输入框共用最大 760px 的阅读轴。手机对话工作区隐藏业务底栏，通过顶栏现有 Radix 抽屉访问其他页面；其他页面保留响应式导航。
3. 字体明确使用本地 Geist → Noto Sans SC → 系统回退；代码使用系统等宽字体，不声明未提供的本地 Geist Mono。Halo 近黑主题保留，侧栏退后、灰阶收敛，正文采用柔白。颜色、排版、布局、圆角与动效集中到令牌。
4. 助手长正文采用开放式排版，用户消息保留中性气泡；授权、工具与结构化结果仍有独立容器和完整状态。输入区只常驻连接器、文本与发送/停止，移除未开放语音占位。查找、复制、取消、重试、Markdown 安全边界与减少动态支持保留。
5. 首批实施覆盖共享外壳、首页/聊天、基础按钮和表单、既有页面共享排版。无数据库或 HTTP 契约变化，不新增真实 Provider、OAuth 或原生能力。

## 限制

公开 ChatGPT/Grok 页面和 Geist 设计系统只作为布局与排版参考，不复制品牌资产或未实现能力。此变更不代表正式双端设计评审、原生真机、真实模型性能或生产准入通过。
