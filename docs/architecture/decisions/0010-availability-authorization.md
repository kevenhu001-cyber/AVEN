# ADR-010：忙闲用途授权与共享模型

- 状态：已接受（M6-01R 实现与本地验证）
- 日期：2026-11-11
- 补充：[ADR-007](0007-authorization-boundaries.md)；遵循 [ADR-005](0005-async-and-outbox.md) 的事务边界
- 相关：[TDD](../TDD.md) · [SCHEMA](../../database/SCHEMA.md) · [日程与活动 API](../../api/AVAILABILITY_EVENTS.md) · [M6 交付记录](../development/M6_CALENDAR_EVENT.md)

## 背景

M6-01 实现了忙闲块与忙闲投影。2026-11-11 安全核对发现，`app.query_availability_window` 只校验调用者已登录，没有校验被查询主体是否授权，导致任意登录用户可以读取他人的忙闲区间。这是私人日程信息泄露，属于规则 6（默认拒绝、发现越权即暂停并修复）范围。

同时 M6-03 的多方求交依赖跨用户忙闲读取，简单关闭会让活动协调不可用。因此需要一个显式、可撤销、有期限的共享模型，而不是永久关闭功能。

## 决策

1. **默认拒绝**：忙闲投影对请求中的**每个**主体逐一校验；不满足则整体拒绝（HTTP 403），不返回部分结果，也不泄露对方是否存在忙闲数据。
2. **本人始终可读**：调用者读取自己的忙闲不需要任何授权。
3. **共享授权模型**：忙闲所有者显式创建共享授权，落库为用途 `event_coordination` 的 `consent_grants` 记录（`referral_id` 与 `event_id` 为空以区别于引荐与关系用途）。授权人是被授权主体的所有者，期限必填且不超过 90 天。
4. **单向性**：授权只从授权人流向被授权人。A 授权 B 不意味着 B 可读 A 以外的任何内容，B 未授权 A 时 A 仍读不到 B 的忙闲。
5. **组织被授权人**：被授权主体可以是个人或组织主体；组织主体被授权时，其当前有效成员可读取（`app.is_org_member`）。
6. **撤销即时生效**：撤销写入 `consent_events` 审计并把授权置为 `revoked`；随后的投影与求交请求立即返回 403，不依赖缓存、任务或批处理过期。已通过检查的在途字节无法收回。
7. **最小披露**：投影只返回主体、时间区间与忙闲状态，不含标题、描述、备注等私人字段。
8. **临时收紧**：在共享模型落地前，先用 `0027_availability_privacy` 收紧为仅本人（fail closed），保证中间状态也是安全的。
9. **失败映射**：数据库错误码统一映射为 HTTP 语义（`42501` → 403、`22023` → 422、`23505` → 409、`P0002` → 404），不回显 SQL 与内部细节。
10. **不采用**：见下方备选方案。

## 备选方案

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 永久只允许本人 | 最简单，零泄露面 | 多方求交不可用，活动协调无法落地 | 仅作临时收紧（0027） |
| 关系存在即互相可读 | 无需额外授权操作 | 授权与关系耦合，撤销关系外的共享无法表达，且扩大暴露面 | 不采用 |
| 独立 `availability_shares` 表 | 语义更专用 | 与撤销、审计、到期事件重复实现，易产生第二套授权真相 | 不采用，复用 `consent_grants` |
| 在应用层过滤（查询全部再过滤） | 数据库改动小 | 越权数据已进入应用进程，违反最小披露与默认拒绝 | 不采用 |
| 忙闲只做本地日历、不共享 | 无泄露风险 | 无法实现活动协调的核心价值 | 不采用 |

## 后果

- 新增 `0029_availability_sharing.sql`（4 个函数）与 `POST/GET/DELETE /api/v1/availability/shares` 三个端点。
- 忙闲共享只区分主体，不区分具体时间窗：授权在期限内覆盖该主体的全部忙闲块。细化到时间窗需要新的授权维度与预览流程。
- 授权使用 `event_coordination` 用途，与引荐用途、关系用途分离；共享忙闲不会升级为关系共享内容。
- 撤销路径与 M5-07 的关系授权撤销保持一致：读取端实时复核，不依赖后台清理任务。

## 验证

- [x] 跨用户读取默认 403，混合主体请求整体拒绝（`m6:verify`、`db:verify`）。
- [x] 授权后被授权方可读取投影，且投影不含私人字段。
- [x] 授权单向生效，反向读取仍被拒绝。
- [x] 自授权、过期期限、超 90 天期限、未知主体、重复授权被拒绝。
- [x] 只有授权人可以撤销；撤销后投影与求交立即 403。
- [x] 空库迁移、升级迁移、迁移与 seed 幂等、数据库回归通过（`db:verify`）。
- [ ] 真实日历连接的凭据撤销与同步失败恢复（M6-02 未实现）。
- [ ] 时间窗粒度的共享授权、界面授权流程与真实设备验证。
