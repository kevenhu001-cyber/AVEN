# ADR-019：个人聊天真实模型接入

- 日期：2026-11-13
- 状态：已接受（用户明确授权，真实成功须另验）
- 部分取代 ADR-006、ADR-017、ADR-018 的本轮个人 Web 默认 Mock 限制；不改写历史验收结论。

## 授权与范围

用户在明确询问“沿用 Socrates 的模型配置，并只发送当前提问及已获授权上下文”后回复“要接入真实的”。本轮允许本机部署的个人聊天使用 Socrates 当前生效的内置模型配置。仅复用该通道所需的 endpoint、model、key；不修改 Socrates，不复用其用户资料、对话、用户私有模型或其他凭据。

## 决策

1. 继续使用统一 OpenAI-compatible Provider，运行配置放在受限服务环境；开发 `.env` 和 CI 默认 Mock。密钥不进入仓库、浏览器、日志或交付记录；服务端模型状态只返回 mock/live 和能力标识。
2. 仅个人 run 可使用真实模型；组织 run 与历史 Mock run 使用 Mock，配置/模型不匹配的真实 run 失败关闭，禁止旧队列因切换环境而意外外发。
3. 外发范围为当前提问和本次已获 self_ai 用途授权、确定性检索命中的记忆片段，不发送完整记忆库、历史对话、组织资料或连接器数据。外发前重新核对来源、保留期与取消状态；撤销不能收回检查后已外发的字节。
4. 模型只生成文字，没有真实邮箱/日历/OAuth、任意网络工具或外部动作能力；提示词和 UI 均明确区分。既有草稿确认路径不由本轮模型自动执行。
5. 上游限流、额度、鉴权、超时和流截断明确报错；不自动换模型、重试外部调用或回退 Mock。需要 [DONE] 才标记成功；部分回复失败时清除派生正文。
6. 先验证传输、数据边界与失败处理，再按真实上游结果记录成功。既有正式设计、生产试点、设备与 APK 门不关闭。

## 当前外部条件

已找到可解密的内置配置及 Socrates 运行服务中的当前模型环境。两种来源的实际调用均返回 429，数据库来源的响应包含额度限制信息。接入代码可继续完成；不能宣称真实回复已成功。已向用户询问恢复原通道额度还是替换可用通道。
