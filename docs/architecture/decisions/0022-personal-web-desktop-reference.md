# ADR-022：个人 Web 桌面对话、Bot 侧栏与应用目录对齐

- 日期：2026-11-14
- 状态：已接受（按用户提供的三张桌面截图对齐）；实际验证见 [WEB-14](../../development/WEB_14.md)
- 仅更新个人 Web 的桌面呈现结构；不改变 ADR-017 的功能、安全和数据边界。

## 背景

用户要求检查当前 UI，并按三张桌面截图尽量一比一对齐。截图覆盖对话工作区、连接应用目录弹层和 Bot 资料侧栏。现有 Web 已有聊天、最近会话、连接器目录及资料路由，但桌面默认显示完整导航，连接应用弹层较窄，Bot 资料仍使用整页路由。

## 决策

1. `/` 与 `/chat` 桌面默认使用收起图标栏，保留用户保存的展开/收起选择。对话工作区使用宽消息列、居中的 Bot pill、右侧分享入口和底部横向输入栏；用户气泡靠右、助手消息靠左。
2. 聊天顶栏的 Bot pill 与侧栏 Bot 标记打开右侧资料面板。桌面面板保持聊天可见并缩窄聊天列，提供「动态 / 资料库」标签；资料库链接到现有「记忆与上下文」页面。窄屏采用全屏面板，不强行压缩为窄侧栏。
3. 连接应用入口使用较宽的居中弹层：顶部展示真实网关连接数、搜索与类别筛选，目录按现有精选/类别分组，桌面双列、窄屏单列。动作仍遵循服务端目录、凭据状态与 Open Connector 当前状态。
4. 资料面板只把已实现的开新对话、连接应用和打开记忆作为可操作入口。电脑与语音模式明确显示「尚未开放」；Bot 模板保持禁用并说明尚未开放。不得把这些占位写成已运行能力。
5. 不改变 API、数据库、授权或连接器执行逻辑，不增加真实 Provider、第三方 OAuth、电脑控制或语音模式。模拟模式标识及连接器、Mock 回复的真实状态文案继续保留。
6. 移动端继续使用既有顶栏/导航抽屉与单列应用列表；本 ADR 不将桌面侧栏直接移植到手机。

## 取代范围

本 ADR 只取代 ADR-021 的个人 Web 桌面布局部分（248/72px 导航选择、760px 对话阅读轴及其输入布局），并补充 ADR-018 中资料入口的桌面呈现。历史决策保留；个人页面能力、API 与数据授权边界不变。

## 备选方案

- 保持现有侧栏和 760px 阅读列，只调整颜色与圆角：无法满足参考图的宽屏对话与两栏目录结构。
- 把 Bot 资料完全移至独立页面：切换时会离开当前对话，与参考图并排查看的关系不符；现有 `/profile` 路由仍保留给完整资料页。
- 让连接应用只使用现有 `/apps` 页面：保留作「查看全部」目的地，但聊天中的常用入口改为弹层，避免丢失当前对话上下文。

## 后果与限制

- 电脑控制、语音模式、Bot 模板仍未实现；侧栏快捷入口不能暗示其可用。
- Gmail 等连接器只按真实网关状态展示；本地模拟运行不等于真实第三方 OAuth 或外部服务已验证。
- 实际视觉对照应使用与截图相同的桌面视口。小视口预览只可验证响应式行为，不能作为桌面逐像素验收。

## 验证

在 WEB-14 记录本轮可访问的渲染视口、交互检查、源码截图与当前实现之间的差异，以及未执行的同尺寸桌面视觉检查。不得把浏览器单一窄视口的截图描述为桌面 1:1 验收。
