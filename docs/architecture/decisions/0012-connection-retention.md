# ADR-012：个人连接正文保留与受控清除

- 日期：2026-11-12
- 状态：已接受，实施与验证记录见本轮交付
- 补充 ADR-007、ADR-011，不更改原用途与确认规则

## 决策与原因

个人连接预览在 10 分钟后不可使用，但目前数据库仍长期保留 manifest 正文；已撤销或失效的邀请快照也没有物理清除入口。可撤销读取与正文保留是两个不同保证，不能用读取拒绝代替数据删除。

新增迁移为预览记录增加 `purged_at`、为授权项增加 `invalidated_at`。只处理 `connection_invitation` 用途，不清理组织引荐、关系或其他业务快照。

- 预览在绝对过期时间满 24 小时后将 manifest 置为空数组，标记清除时间。保留预览元数据与邀请引用，保证已发送请求的幂等重放继续工作。
- 授权项第一次失效后不复活。用途收紧、来源删除/失效触发器设置首次失效时间；维护也扫描授权/来源/双方当前状态及到期，不依赖另一个清理任务先运行。
- 已有失效记录缺少确切时间：已知授权撤销/到期可用已知时间；其他 stale 项从迁移时间开始计时，避免猜测并提前清除。
- 失效满 30 天后将正文替换为 JSON null，记录 `purged_at`，保留来源/版本/授权元数据并追加不含正文的 `purged` 授权事件。正文不可替换、失效/清除不可逆；新共享必须重新预览并创建新邀请。
- 不修改邀请的业务状态、版本、期限或已建立连接。正文清除不会赋予新权限，也不会删除必要幂等信息。
- 只有真实 `aven_worker` 会话可调用受控维护函数；不使用可写 GUC 提权。固定 24 小时/30 天期限，批次为 1–1000，行锁与 SKIP LOCKED 支持重复/并发维护，输出只有计数。

提供显式维护命令；生产定时编排、运行告警、授权事件保留与用户删除申请流程另行交付。本轮不把手动维护称为自动调度或 M7 完成。

## 备选与验证

直接删除已消费预览会破坏外键与幂等重放，不采用。只清空授权项而保留预览副本仍残留私人正文，不采用。让普通 API 执行全库清理扩大权限，不采用。

验证固定保留边界、未过期/未满保留期保护、部分来源失效、重复/并发调用、锁冲突跳过、清除不可复活、幂等重放与接受失败、外用途隔离、普通池/伪造 Worker 上下文拒绝，以及空库/升级迁移与已有业务回归。
