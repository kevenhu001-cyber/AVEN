# ADR-020：复用 Socrates 图标与显式网关环境密钥

日期：2026-11-13。状态：已接受（用户明确允许使用 Socrates 中配置的 SVG 和管理员密钥）。

部分取代 ADR-018 不内置品牌图标的决定：从用户本地 Socrates 复用 Gmail、QQ 邮箱、高德、Outlook、Google Drive、Google Calendar 共 6 个 SVG，检查无脚本、事件处理或外部资源引用，作为本地静态图片展示，不使用原始 HTML 注入。保留原来源说明；其他服务继续使用类别图标，不制作冒充官方的资源。

网关密钥可使用运维显式配置的 `OOMOL_PROJECT_API_KEY`，仅在没有管理员数据库配置时读取；已有数据库配置无效时拒绝，不静默退回环境密钥。沿用固定 OOMOL 网关、精确 HTTPS 授权域名及无自动重试。授权域名未配置时在创建远端请求前拒绝。

本次仅在被 Git 忽略的本地环境文件配置现有网关密钥，不复制模型密钥、不修改用户管理员角色、不改 Socrates 或生产环境文件，不自动发起真实用户 OAuth。密钥不得进入日志、源码、测试、文档或提交。
