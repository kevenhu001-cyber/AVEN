# ADR-019：管理员配置、Open Connector 与原生增量

日期：2026-11-13。状态：已接受（用户本轮明确授权）。

用户要求管理员手动配置模型、参考本机 Socrates 经 Open Connector 授权，并继续完善原生端与生产运行保障。本决策取代 ADR-017 中禁止开始上述范围实现的限制，不代表生产准入、真实数据发送或设备验收完成。

管理员通过平台角色管理独立的平台模型与 OOMOL Open Connector 配置，不复用用户级模型设置；配置密钥仅加密入库，不返回浏览器，使用版本控制避免覆盖。初期配置不自动启用模型调用。OAuth 使用 OOMOL ProjectConnector 渠道，采用服务端用户绑定、固定回跳地址、显式用户确认与状态回查；真实联调必须有有效平台配置，不把模拟授权视为真实连接。

原生端先建立原生登录与受保护的本人数据读取，不使用 WebView、不保存明文密码或令牌；生产保障先增加只读配置检查和操作文档，不能以检查脚本代替部署、备份恢复或告警实跑。
