## 3. 状态矩阵

| 页面 | loading | empty | error | success | disabled | permission denied |
|---|---|---|---|---|---|---|
| 今日 | 适用：同步待办 | 适用：无待办→发现 | 适用：同步失败→重试 | 适用：默认 | 适用：AI 无上下文时禁用发送 | 不适用：本人数据，无第三方权限 |

## 5. 视觉与无障碍自检

- 令牌来自 M1-01；正文/辅助/状态色对比度由令牌测试覆盖，原型未重新定义颜色。
- 中性色为主、细边框、少量强调色；未使用渐变、玻璃拟态、Emoji 图标或指标卡堆砌。
- 页面标题、当前对象、状态、一个主要操作的信息顺序一致。
- 对话框使用 `role="dialog"`、`aria-modal`、Escape 关闭、焦点陷阱与关闭后焦点恢复。
- 顶部状态提示使用 `aria-live`；导航使用 `aria-current`；身份切换使用 `aria-pressed`。
- 跳过链接、`:focus-visible`、44–48px 触控目标、`prefers-reduced-motion` 已覆盖。
- 长标题允许换行；移动端主操作在正常文档流中，不覆盖最后一段正文。
- 字体使用系统中文回退，不依赖外部字体 CDN。

## 6. 未决问题

| 问题 | 影响 | 建议 |
|---|---|---|
| 个人底栏标签 | 契约写“今日、发现、空间、我的 AI”，原型使用“今日、发现、引荐、空间、隐私” | 评审决定“我的 AI”是否替换“引荐”或“隐私”；隐私必须保持可达 |
| 组织代表范围文案 | “当前有代表权限的成员可读”需要产品/法律确认 | 评审确认是否显示成员数量或角色范围 |
| 撤销成功文案 | “已送达内容或系统外副本无法收回”需隐私/法律确认 | 评审后冻结文案 |
| 关系用途独立授权 | 原型只有空状态与入口，未设计完整关系资料预览 | M1-07 后续补充或明确延后到 M5 设计 |
| 桌面授权预览形态 | 原型使用完整页面；契约允许宽 Dialog | 评审选择；建议完整页面以容纳字段级检查 |
| 移动端身份切换 | 原型放在顶部工具栏 | 评审是否改为头像/身份菜单 |
| 状态变体覆盖 | 仅 3 个页面有完整状态块 | 组件实现时按矩阵补齐，不能只做默认态 |
| 真机与放大 | 未测 200% 文字、屏幕阅读器、中文输入法 | 实现后补测，不以 Web 原型代替 |
