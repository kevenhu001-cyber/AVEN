## 设计方向

依据用户提供的四张 ChatGPT 深色界面截图，采用近黑背景、大面积留白、低对比表面、圆角输入区、线性图标、侧栏和头像菜单。页面仍使用 AVEN 的中文信息架构、用途授权和组织边界，不复制订阅、插件、语音或浏览器外壳。

- 桌面：248px 侧栏，支持收起；AI 正文最大 760px 左右，业务列表独立布局。
- 平板：68px 图标栏。
- 手机：四项主入口“今日、发现、空间、我的 AI”，次级抽屉和头像菜单；设置采用列表进入详情。
- 默认深色，可在“设置 → 外观”或“设计检查”切换浅色。
- 11 个设计视图：我的 AI、今日、发现、机会详情、授权预览、我的引荐、组织收件箱、关系空间、隐私与授权、我的记忆、设置。

## 使用方式

直接在浏览器打开 `index.html`。页面自包含，不需要安装依赖、启动服务器或连接网络。支持 `#ai`、`#discover`、`#consent`、`#settings` 等设计状态链接；这些是原型定位符，不是产品规范路由。

建议评审路径：

1. 我的 AI：输入演示消息、停止、选择本次上下文；中文组合态 Enter 不发送。
2. 发现：搜索/领域筛选 → 机会详情 → 预览并申请引荐。
3. 授权：勾选实际字段、选择引荐期限；独立关系用途默认不勾选。确认对话框可取消，未选字段时禁用发送。
4. 头像 → 切换组织 → 收件箱 → 接受并建立关系；没有关系用途授权时共享上下文为空。
5. 头像 → 隐私：逐用途查看快照与撤销。撤销引荐授权不影响独立关系授权，撤销关系授权才隐藏对应共享上下文。
6. 我的记忆：复核样例候选并查看更新后的数量。
7. 设置：常规、外观、通知、数据与隐私、AI 服务。通知仅演示偏好，不投递；AI 服务不采集密钥。
8. 页面下方“设计检查”：查看加载、空、失败、无权限和不可操作的恢复状态。

## 边界

全部是设计样例。发送、接受、复核和撤销只修改内存中的演示状态，刷新后重置。不调用账号、模型、数据库、消息、通知、日历或任何真实业务 API；没有持久化。附件、语音和关系会话显示未开放。设置开关不代表通知模块已实现。

本目录保留 Lucide Static 0.468.0 的所需图标源码与 MIT 许可（`LUCIDE_LICENSE`），不依赖图标 CDN。头像使用姓名回退，不使用截图中的账号资料。`checks.js` 是本原型的交互检查，不是业务 E2E、API 验收或原生真机测试。

v0.1 原型保留于 `../m1-07/`。原型视觉主题是评审方案，尚未写入 `packages/design-tokens` 或产品应用。
