## 修复历史

1. P2：320 CSS px、200% 文字下 AI 输入栏横向溢出。修复：工具栏允许换行，长消息允许断行；修后 320、390、768、1024、1440 五个宽度均无页面横向溢出。
2. P2：手机设置起初采用横向分类，未形成参考图的纵向列表层级。修复：改为列表进入详情，并有返回设置入口；修后截图见 `mobile-settings.png` 和并排比较。
3. P2：程序化导航后主区出现整块焦点描边。修复：保留主区焦点移动，去除非交互主区外框，交互控件焦点环保留；修后截图见 `mobile-settings.png`、`mobile-consent.png`。
4. 交互检查补齐：引荐授权与关系用途分开撤销，组织读取未选字段不会显示，切换个人记忆时显式回到个人身份。

## 检查限制与后续

- 已验证的键盘行为为组合态 Enter、对话框取消/确认、抽屉 Escape 和焦点恢复；没有宣称全键盘或屏幕阅读器验收通过。
- 没有原生设备、软键盘、动态字体、后台恢复、真实授权读取或业务 E2E 证据。
- 完整逐状态视觉基线、自动无障碍扫描、Android/Windows 字体、浅色逐页对比仍需后续补验。
- 本原型不提供登录/注册、完整个人资料编辑、组织机会与成员管理、日程等所有产品页面；本轮聚焦核心旅程与 AI/设置设计。
- 需至少一名产品与一名工程正式评审；人工评审未完成，不解除 M1-07 UI 编码门。
