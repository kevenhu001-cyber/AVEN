## v0.4 按用户图片对齐

本轮依据用户提供的 Gmail / Outlook 手机截图重新调整视觉：默认浅色、浅灰回复气泡、黑色用户气泡，气泡 26px、连接器卡片 28px，图标按钮和输入栏为圆形/胶囊；SVG 端点、连接与矩形内部转角同步圆润化。压缩消息和工具间距，手机输入栏收为约 44px 单行胶囊，多行自然增高。桌面使用同一组件与更窄的会话栏，深色保留对应结构。

默认场景为 Gmail 横向授权卡；底部“Outlook”展示灰底堆叠卡与整行关联按钮。“授权/关联”先展示范围确认，再由“同意并继续演示”进入模拟已连接；支持取消、离线禁用和单独确认断开。没有真实 OAuth、邮箱读取、外部请求或凭据保存。Gmail 与 Outlook 的演示状态相互独立，Outlook 不是本轮新增后端连接器。

连接器目录同步采用品牌图标与圆角列表。品牌图标来自 Google / Microsoft 官方静态资产，Lucide 使用已有许可与官方 SVG；未复刻参考图的其他应用品牌、验证徽章、账号内容、系统状态栏或底部业务导航。新方向优先于下文 v0.3 的黑色默认主题和开放式助手正文。

检查入口：`PLAYWRIGHT_CHANNEL=chrome node scripts/design-prototype-verify.mjs`。新增 `connector-checks.js`，连同既有同步与异步交互检查覆盖五个宽度；截图自动写入系统临时目录。结果与同尺寸对照见 [设计自检](design-qa.md)。原型文件继续放在原路径以保留既有入口，M1-07 仍为 REVIEW。

## v0.3.1 交互打磨

保留既有视觉方向，不新增业务首页。新增草稿按模拟终端隔离（仅内存，刷新清空）、插件/上下文选择后保留输入、多行自适应、接近字数上限提示、空白/离线禁发；增加回复失败与手动重试、向上阅读时保持位置和“回到最新消息”。侧面板补齐模态语义、完整焦点循环与返回，工具菜单支持方向键/Home/End/Escape。手机首页改为正常流布局，避免多行输入与建议重叠。授权预览实时显示勾选数量，接收方离线隐藏授权资料。

底部“切换离线”“下次回复失败”仅为设计场景控件。重试仅生成固定演示回复，不重发邀请、不执行插件；恢复连接不自动发送。共同对话入口已更正文案：个人连接消息后端存在，但原型未接入，组织关系空间会话仍未实现。

`checks.js` 为已有同步检查；`interaction-checks.js` 为新增异步回归检查，在原型加载后注入并等待 `window.avenInteractionChecks`。实际命令、浏览器与检查范围见 [设计自检](design-qa.md)。

## 本轮方向

AVEN 是具有社交与跨终端连接能力的 AI 对话产品。聊天是主体验，连接人与业务能力按需出现。此前 v0.2 的业务页面导航已被用户否定，本稿替代其推荐地位。

- 视觉适配用户本机 Socrates 项目的成熟 UI：Geist Sans / Noto Sans SC、黑灰表面、260px 侧栏、52px 桌面顶栏、输入框和插件菜单语法。
- 用户最新要求：精致圆角、无阴影、无发光、无渐变或模糊。输入区 26px、卡片/浮层 20px、按钮/菜单行 12px、标签 8px，以背景与细边框分层。
- 新对话与最近会话为主；插件和我的连接为次级入口。手机没有业务底栏，只有聊天、输入区和抽屉。
- 普通回复保持自然正文。相关话题中才出现“或许可以认识一下”的小组件，邀请、共享和回应在原对话上下文中进行。

## 可点击路径

1. 默认打开带连接建议的对话。点击“认识一下”只打开共享预览，不发送。
2. 勾选实际字段 → “确认并发送” → 等待对方回应。
3. 使用原型外的“对方终端”检查接收视角；确认发送前为空，只能看到已选字段。对方可独立接受或拒绝。
4. 回到“连接小组件”查看双方决定；“共享范围”可单独查看快照与撤销。
5. “空白对话”回到安静的首页；输入框加号打开插件/上下文菜单，选中后显示可移除的 Chip。启用插件不授权对外共享。
6. 插件目录可启停连接能力；机会能力可加入对话；协作插件标明计划中。头像菜单提供记忆、隐私与设置，支持浅深色。

直接在浏览器打开 `index.html`，无需启动服务、构建或联网。内嵌字体和官方 Lucide 图标，附图标许可。

## 模拟边界

所有用户、消息、推荐和状态均为内存设计样例，刷新后重置。两端切换只模拟独立用户视角，不连接两个真实设备或账号。没有真实模型、通知、插件执行、关系消息或人际连接服务。

现有后端已分别提供组织引荐与个人连接邀请/消息契约；本原型仍只模拟交互，没有接入它们，不能把个人连接等同于组织关系空间。共同对话入口明确说明个人消息后端存在但原型未接入，组织关系会话仍待实现。授权撤销不承诺收回已送达或系统外副本。

本轮不修改 `apps/web`、`apps/mobile`、数据库或 Socrates 项目，不解除 M1-07 的正式设计评审门。
