## 本轮方向

AVEN 是具有社交与跨终端连接能力的 AI 对话产品。聊天是主体验，连接人与业务能力按需出现。此前 v0.2 的业务页面导航已被用户否定，本稿替代其推荐地位。

- 视觉适配用户本机 Socrates 项目的成熟 UI：Geist Sans / Noto Sans SC、黑灰表面、260px 侧栏、52px 桌面顶栏、输入框和插件菜单语法。
- 用户最新要求：精致圆角、无阴影、无发光、无渐变或模糊。输入区 26px、卡片/浮层 20px、按钮/菜单行 12px、标签 8px，以背景与细边框分层。
- 新对话与最近会话为主；插件和我的连接为次级入口。手机没有业务底栏，只有聊天、输入区和抽屉。
- 普通回复保持自然正文。相关话题中才出现“或许可以认识一下”的小组件，邀请、共享和回应在原对话上下文中进行。

## 可点击路径

1. 默认打开带连接建议的对话。点击“认识一下”只打开共享预览，不发送。
2. 勾选实际字段 → “确认并发送” → 等待对方回应。
3. 使用原型外的“对方终端”检查接收视角；确认发送前为空，只能看到已选字段。对方可独立接受或拒绝。
4. 回到“连接小组件”查看双方决定；“共享范围”可单独查看快照与撤销。
5. “空白对话”回到安静的首页；输入框加号打开插件/上下文菜单，选中后显示可移除的 Chip。启用插件不授权对外共享。
6. 插件目录可启停连接能力；机会能力可加入对话；协作插件标明计划中。头像菜单提供记忆、隐私与设置，支持浅深色。

直接在浏览器打开 `index.html`，无需启动服务、构建或联网。内嵌字体和官方 Lucide 图标，附图标许可。

## 模拟边界

所有用户、消息、推荐和状态均为内存设计样例，刷新后重置。两端切换只模拟独立用户视角，不连接两个真实设备或账号。没有真实模型、通知、插件执行、关系消息或人际连接服务。

现有后端主要覆盖个人到组织的引荐；本稿的个人到个人连接需要后续独立契约与实现，不能直接套用机会引荐接口。共同对话入口明确显示关系会话 API 尚未实现，不伪造可用聊天。授权撤销不承诺收回已送达或系统外副本。

本轮不修改 `apps/web`、`apps/mobile`、数据库或 Socrates 项目，不解除 M1-07 的正式设计评审门。
