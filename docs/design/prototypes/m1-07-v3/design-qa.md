## 修复历史

- P1：前版业务导航喧宾夺主。依用户反馈改为会话优先；连接、授权与回应作为小组件，插件从输入区选择。
- P2：桌面 Grid 子项撑大导致头像与输入尾注裁切。补充工作区 `min-height: 0` 和 Grid 行约束，复查桌面渲染。
- P2：手机首屏连接小组件的主操作被下方输入区挤出滚动视口。压缩辅助元信息与回复长度；390px 下按钮位于输入区上方，已加入断言。
- P2：接收方接受后固定文案泄露未选择的显示名。改用已确认快照值或“对方”，确认前无资料，撤销后移除授权内容。
- 视觉修订：移除阴影与发光，圆角按用户要求统一；实线键盘焦点保留。

无待修复的 P0/P1/P2 原型问题。此结论不代表用户已经认可视觉或正式双端评审通过。
