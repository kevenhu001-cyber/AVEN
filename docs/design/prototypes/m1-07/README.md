# M1-07 核心旅程设计原型

版本：v0.1 · 日期：2026-11-11 · 状态：可点击原型已交付，正式双端评审待完成

## 打开方式

直接打开 `index.html`，或在本目录运行任意静态文件服务器。原型不依赖构建、网络或后端。

```bash
cd docs/design/prototypes/m1-07
python3 -m http.server 4173
# http://127.0.0.1:4173
```

## 覆盖页面

| 页面 | 个人/组织 | 说明 |
|---|---|---|
| 今日 | 个人 | 待办、有依据的机会、个人 AI 输入 |
| 发现机会 | 个人 | 查询/筛选、推荐依据、无结果/资料不足 |
| 机会详情 | 个人 | 组织与认证、要求、投入/截止、推荐依据 |
| 授权预览 | 个人 | 接收方、引荐/关系用途分离、字段实际值、不共享项、期限 |
| 我的引荐 | 个人 | 状态时间线、补充资料、撤回 |
| 组织收件箱 | 组织 | 主从列表、获授权快照、接受/补充/拒绝 |
| 关系空间 | 个人 | 参与者、共同目标、下一步、空共享上下文 |
| 隐私与授权 | 个人 | 有效授权、未授予、历史、撤销确认 |

组织机会与成员页保留为“未展开”占位，但**不进入导航**，避免把未开放模块常驻入口。

## 交互

- 身份切换：个人/组织；移动端顶部提供切换按钮。切换后导航、标题、上下文说明同步变化。
- 主题：浅色/深色切换；默认浅色。
- 状态预览：顶部下拉切换 loading/empty/error/denied/disabled；发现、收件箱、引荐有完整状态块，其他页面显示“见评审矩阵”提示。
- 授权预览：勾选/取消字段会更新摘要；关系用途默认不勾选，勾选后显示独立确认提示。
- 发送：显示成功提示并进入“我的引荐”，状态变为“已发送，等待组织查看”。
- 收件箱：接受打开确认对话框，确认后进入关系空间；拒绝/补充资料分别有确认或提示。
- 撤销：打开包含接收方、用途、字段、期限与撤销边界的确认对话框；确认后显示精确成功文案。
- 对话框：Escape 关闭、焦点陷阱、关闭后恢复焦点。
- 移动端：底部导航、Safe Area 预留、无横向溢出。

## 数据与边界

- 所有组织、用户、机会、授权与消息均为脱敏中文样例；邮箱使用 `.test` 保留域。
- 组织认证状态明确为“未认证”，不伪造官方背书。
- 不调用模型、搜索、日历、消息或后端；所有按钮只演示界面状态。
- 分享/撤销文案是设计稿，需产品、隐私与法律评审后才能进入实现。

## 令牌与响应式

- `tokens.css` 是 M1-01 生成令牌的快照；令牌变更后需重新复制。
- 桌面：侧栏 + 主区 + 上下文面板；宽度 <1200px 隐藏上下文面板，<900px 切换为移动底栏。
- 字体使用系统中文回退；不加载外部字体 CDN。
- `prefers-reduced-motion` 下动效时长归零。
